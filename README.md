# Msports

Catálogo virtual responsive para una tienda de ropa deportiva y urbana.

## Características

- Catálogo de productos
- Filtros por categoría
- Buscador
- Carrito simple
- Pedido por WhatsApp
- Diseño responsive para móvil y escritorio
- Compatible con GitHub Pages
- Sin backend ni instalación

## Personalización rápida

1. Abre `app.js`.
2. Cambia `WHATSAPP_NUMBER` por el número real de WhatsApp con código de país.
3. Edita el arreglo `products` para cambiar nombres, categorías y precios.
4. Puedes reemplazar los emojis por imágenes reales más adelante.

## Publicar en GitHub Pages

En el repositorio:
`Settings > Pages > Deploy from a branch > main / root`

Después GitHub mostrará la URL pública del catálogo.
